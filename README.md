# 47分の1

今日、日本で生まれる赤ちゃんのひとりになって、一度きりの人生を最後まで生きるブラウザ用の人生シミュレーションです。
生まれる場所は47都道府県のどこかにランダムに決まり（選べません）、その県の公的統計に沿って人生が進みます。

世界172の国と地域を舞台にした「80億分の1」（1in8b.life）に着想を得た、非公式の日本版です（元の作品の運営とは関係ありません。文章・コード・画像はすべてこの作品のために作成）。

## 遊び方

1. トップで設定（任意）を選び「生まれる」
   - 生まれる場所の決め方：「いま生まれる赤ちゃん」（県別出生数の割合）／「いま日本に住む人」（県別人口の割合）
   - ひとつの人生の長さ：約30分／約1時間／約1時間30分
   - あなたが実際に生まれた都道府県（比較用・端末にだけ保存）
   - 怖い場面を除く／音楽
2. 出生届（名前・県・家族・暮らし向き・その県に生まれる確率・同じ日に生まれた4人）を見て「人生を始める」
3. 毎年「今年の重点」を選び、決断の場面で選ぶ（「おまかせ」で自動にもできる）
4. 5・15・30・50・70歳で「ひと息」。人生の最後に「最期の記録」とひとこと

操作：スペースで一時停止／再開、`N` で「次の決断まで」、決断カードは数字キー `1`〜`9` でも選べます。

## ローカルで起動

ビルドは不要です。データを `fetch` で読むため、ファイルを直接開くのではなく、ローカルサーバーで開いてください。

```bash
npm start          # Node.js 18 以上。http://localhost:8047/
# または
python3 -m http.server 8047
```

## テスト

```bash
npm test           # 1000人ずつシミュレーションして統計との一致を確認（約10秒）
SIM_N=3000 npm test  # 人数を増やす場合
```

確認している内容：出生地の抽選が県別出生数の割合どおりか／県別生命表の平均寿命との一致（全国・東京・秋田・沖縄）／大学等進学率・合計特殊出生率・50歳時未婚割合・賃金センサスの平均年収・主な死因の割合／重い出来事の頻度／同じ種での再現性と保存からの再開。

## 公開中のサイトと更新のしかた

公開URL：**https://k2-so-01.github.io/-/**

`main` ブランチに push（またはプルリクエストをマージ）すると、GitHub Actions（`.github/workflows/deploy.yml`）が自動で

1. `npm test`（1000人シミュレーションで統計との一致を確認）を実行し、
2. 合格したら `index.html`・`stats.html`・`about.html`・`assets/`・`data/` を `gh-pages` ブランチに書き出し、
3. GitHub Pages がそのブランチを公開します（反映まで1〜2分）。

テストに失敗した変更は公開されず、前のバージョンが表示されたままになります。Actions タブから「テストして公開」を手動で実行することもできます。

初回だけ、リポジトリの Settings → Pages で「Source: Deploy from a branch」「Branch: gh-pages / (root)」になっているか確認してください。

統計データを更新するときは `data-raw/` を直して `npm run build:data` で `data/japan.json` を作り直し、`npm test` が通ることを確かめてから push します。

## ほかの場所に公開する場合（静的サイト）

リポジトリのルートをそのまま公開すれば動きます（ビルド不要）。

- **GitHub Pages**：リポジトリの Settings → Pages → Source を「Deploy from a branch」、ブランチとフォルダ `/ (root)` を選んで保存
- **Netlify**：「Add new site → Deploy manually」でこのフォルダをドラッグ＆ドロップ（Publish directory はルート）
- **Vercel**：New Project でリポジトリを選び、Framework Preset を「Other」、Build Command なし、Output Directory はルート

## ファイル構成

```
index.html / stats.html / about.html   画面（トップ・プレイ・最期の記録 / 47都道府県の統計 / しくみ・出典・相談先）
assets/css/app.css                     スタイル（ライト・ダーク）
assets/js/engine/                      抽選・人生エンジン（DOM に依存しない。Node でも動く）
assets/js/ui/                          地図・グラフ・共有画像・音楽（Web Audio で生成）
data/japan.json                        すべての統計（出典・調査年・県別/全国・推計フラグつき）
data-raw/                              japan.json の元データ
scripts/build-data.mjs                 data-raw → data/japan.json（npm run build:data）
tests/                                 1000人シミュレーションのテスト
```

## データ

すべて `data/japan.json` の `sources`（出典）と `indicators`（指標ごとの出典・調査年・県別/全国・推計）に記録しています。画面では「47都道府県の統計」「しくみと出典」ページで確認できます。

主な出典：総務省「住民基本台帳に基づく人口動態」（県別出生数 2024年）／国勢調査・人口推計（県別人口 2025年）／厚生労働省「令和2年都道府県別生命表」（平均寿命）／国立社会保障・人口問題研究所「日本版死亡データベース（JMD）」（県別・年齢別死亡率）／e-Stat 統計ダッシュボード・社会・人口統計体系（県民所得、課税対象所得、大学等進学率、県内大学入学者割合、合計特殊出生率、婚姻率、離婚率、自殺死亡率、刑法犯、交通事故、医師数、病床数、失業率など）／国勢調査2020（産業別就業者）／人口動態統計2025確定数・2024概数（全国の出生・死亡・死因）／令和6年簡易生命表／令和6年賃金構造基本統計調査／2025年国民生活基礎調査／令和6年国民健康・栄養調査／警察庁・厚労省「令和6年中における自殺の状況」／内閣府「男女間における暴力に関する調査」／明治安田生命「2025年生まれの子供の名前調査」／森岡浩「都道府県別名字ランキング」／全国地震動予測地図・J-SHIS

### 推計・代用している項目

| 項目 | 内容 |
|---|---|
| 県別の年齢別死亡率 | 県別生命表の年齢別の値を直接取得できなかったため、JMD の県別死亡率（2015〜2019年平均）を平滑化し、令和2年都道府県別生命表の平均寿命に一致するよう比例調整 |
| 県別平均寿命の年次 | 県別生命表の最新は2020年。全国の最新（2024年簡易生命表）より0.4〜0.5年長い |
| 死因の年齢・性別の構成 | 人口動態統計の年齢別死因表を取得できず、公表事実（主な死因の割合、年齢層ごとの第1位、年齢別自殺者数）に合うよう推計。県差は自殺と交通事故のみ |
| 賃金の年齢カーブ | 賃金センサスの男女別平均と賃金ピークから内挿。県差は課税対象所得の全国比を0.7乗 |
| 専門学校・短大・大学院の進学、高校中退、いじめ | 全国の近年の水準を仮定 |
| 結婚・出生・離婚のタイミング | 50歳時未婚割合・平均初婚年齢（2019年）・県別合計特殊出生率・離婚率に合うよう較正 |
| 喫煙・依存症・うつ病・要介護 | 全国値または調査水準。県別の喫煙率は未取得 |
| 他県への移住 | 2025年の都道府県間移動者数と整合するよう年齢別に設定 |
| 地震の確率 | 取得できた22都道府県以外は、その中央値で代用 |
| 名字・名前 | 名字は県内上位5姓（一部10〜15姓）、人数は順位から推計。名前は順位から重みを推計、読みは一般的な読み。ランキング外・親世代の名前は作者作成 |
| 性暴力の被害経験（男性） | 男性の値を取得できず推計 |
| 50歳時未婚割合・認知症有病率 | 公表値だが今回の環境では原典で照合できず（未照合） |

## 元の作品と変えたところ

- 生まれる場所：172の国と地域 → 47都道府県（出生数／人口の割合で抽選）
- 時代は「いまの日本」のみ（過去・未来の世界はなし）、メモリアル・みんなの人生・記録の移行・有料パスはなし
- 「同じ1秒に生まれた人たち」→「同じ日に生まれた4人」（日本の出生は約47秒に1人のため）
- 金額は円表示（購買力平価の換算なし）
