# 数学ファクトリー

高校数学（数I・A・II・B・C／数IIIは除く）の問題を解いて工場を動かし、赤い異星生物から守り、ロケットで星を脱出する――
自動化（ファクトリオ風）× ローグライクのカードバトル × 相棒の育成 × 宇宙の勢力争い の受験勉強ゲームです。
ブラウザだけで動きます（ビルド不要・課金要素なし）。

## 遊び方

`index.html` をブラウザで開くだけ。スマホでもパソコンでも遊べます。進み具合はブラウザに自動保存されます（設定から書き出し・読み込み・リセット）。

1. **計算**：問題に正解すると、分野ごとの資源が手に入る（二次関数→鉄、確率→銅、微分→石炭、数列→石材、ベクトル→ウラン、積分→シリコン、三角関数→石油）。
   答えは数字で入力（分数は `3/4`、負の数は `-2`）。まちがえるとヒント1→ヒント2→完全解説の順に開く。連続正解でコンボ倍率。難易度は正答率で自動調整。
2. **工場**：鉱脈に採掘機、ベルトでコアへ。溶鉱炉・組立機・研究所・発電所・倉庫・供給ポート・砲台・ロケット発射台。
   🧠演算チャージ（正解でたまる）が切れると工場は25%の速さに＝勉強した分だけ工場が動く。留守中も最大8時間生産。
3. **研究**：研究ポイント＋指定分野の正解数で、新しい設備や倍率アップを解放（「難」の正解は2問ぶん）。
4. **相棒**：正解でときどき卵。孵化したオリジナルの相棒21種は、同じ分野の問題で育ち、工場の設備で働く。
5. **防衛**：襲撃が来たらカードバトル。カードを使うたびに問題が出て、正解で発動（15秒以内なら会心）。侵攻ラン（10層のローグライク）もある。
6. **受験**：弱点リストと復習（3段階で卒業）、分野ごとの間隔反復、模試（得点・偏差値の目安）、統計、週間レポート、試験日カウントダウンと時期別メニュー。
7. **銀河**：ロケットで脱出すると銀河マップへ。植民した星では新しい分野（指数・対数／場合の数／複素数平面／図形と方程式）が出る。ライバル帝国と交易・同盟・戦争。
8. そのほか：ストーリー（7章17ミッションがチュートリアルを兼ねる）、実績と称号、ログインボーナス、1日の目標、日替わりチャレンジ、着せかえガチャ（研究P）、
   ポモドーロタイマー、効果音とBGM（オン・オフ）、文字サイズ・動きを減らす・ハイコントラストの設定。

## claude.ai のアーティファクトで遊ぶ

`artifact.html` はアーティファクト用のページです（`index.html` から `node tools/make-artifact.js` で作る。直接は編集しない）。
公開するときは `artifact.html` と、`artifact-files.json` に並んでいる CSS・JS をいっしょに公開します。
アーティファクトの中ではファイルのダウンロードができないので、セーブの書き出しは「コピー」で行います。

## つくり

```
index.html, style.css
js/logic/   ゲームのロジック（画面にさわらない。Node から読み込んでテスト・シミュレーションできる）
  util.js questions.js game.js factory.js research.js pals.js battle.js meta.js study.js wellbeing.js galaxy.js story.js balance.js
js/ui/      画面（DOM・キャンバス・音・演出）
js/main.js  起動・メインループ・保存
tests/      自動テスト
sim/        バランス調整用の自動プレイシミュレーション
```

問題はすべてその場で生成（11分野×易・普・難、86パターン）。同じシードなら同じ問題になるので、弱点リストは同じ問題を出し直せます。

## テスト

```bash
node tests/run.js            # ロジックのテスト（86件）
node tests/ui-smoke.js       # 画面のテスト（Playwright・PC/スマホ）
node tests/ui-story.js       # オープニング〜最初のミッション
node tests/ui-newplayer.js   # 新しいプレイヤーの操作でミッション1〜3
node tests/ui-progress.js    # 全17ミッションを画面操作で進め、表示とデータのずれを点検
node tests/ui-noreroll.js    # 問題の引き直し・途中で抜けたとき（読み直し・Esc）の点検
node tests/ui-monkey.js [回数] [シード]  # ランダム操作でエラーや表示のおかしさを探す
node tests/ui-tour.js <dir>  # 全画面のスクショとはみ出しチェック
```

## バランス調整シミュレーション

```bash
node sim/simulate.js --runs 100 --hours 30
```
正答率50%・70%・90%のボットが遊び、序盤・中盤・終盤・クリアまでの時間、襲撃とボス戦の勝率、資源の余り、エラーと詰まりを集計します。
調整前後の比較は [`sim/REPORT.md`](sim/REPORT.md)。
